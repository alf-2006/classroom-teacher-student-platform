# أصول مشهد السكرول

`render.html` مش صفحة موقع أو landing مستقلة. ده مشهد تصدير داخلي غير متاح كمسار عام، وفيه صور PNG مضمنة من واجهة Classroom التوضيحية الحالية. الدالة `window.pose(progress)` بتعيد تركيب نفس الصور بزوايا وعمق مختلفين، من غير توليد نص عربي داخل الصورة أو نسخ أصول منتجات الفيديو المرجعي.

الأصول العامة الناتجة موجودة في `public/scroll-sequence/v1`: 96 إطار WebP للديسكتوب و48 إطار أخف للموبايل، بالإضافة إلى poster وmanifest. كل بيانات الصور توضيحية مش حسابات حقيقية. البادئة `v1` جزء من اسم إصدار الأصول؛ عند تغييرها، صدّر مجلد إصدار جديد وحدّث `SEQUENCE.path` بدل تغيير محتوى الملفات القديمة تحت نفس الاسم.

لإعادة التصدير، افتح مشهد التصدير في Chromium بأبعاد 960×720 واستدعِ `window.pose(i / 95)` قبل تصوير كل إطار. أعد ترميز اللقطات كـ WebP بجودة 78، ثم صغّر كل إطار زوجي للموبايل إلى 640×480 مع الحفاظ على النسبة. الصور المضمنة لقطة محفوظة من واجهة الإصدار الحالي؛ تحديث محتوى الواجهة يتطلب التقاط المصدر التوضيحي الجديد أولًا. أدوات التصدير مش مطلوبة في build أو runtime الموقع.
