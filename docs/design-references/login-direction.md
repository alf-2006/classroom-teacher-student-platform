# Login — Material-inspired calm

المطلوب من المستخدم هو صفحة دخول فخمة شبيهة بهدوء Google، لا تسجيل دخول إلى Google أو ادعاء شراكة. المرجع المختار توزيع أفقي ببطاقة بيضاء على خلفية فاتحة مع outlined fields وزر pill. تم الاحتفاظ بعلامة Classroom وخط IBM Plex Sans Arabic وIndigo. لا يوجد شعار Google أو Google OAuth.

المرجع الرسمي يصف تحديثًا بصريًا فقط ويحافظ على الوظائف. هذا هو حد التعديل لدينا أيضًا: Supabase phone/password وvalidation وsafe return paths لم تتغير. صفحة التسجيل وlanding تبقيان كما هما.
