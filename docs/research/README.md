## اللي هنطبقه (بهوية خاصة بينا، من غير نسخ محتوى أو شعارات)

1. قلب الإحساس 180 درجة: من الكحلي الداكن لـ«ورق الكراسة» الفاتح، بحبر أزرق «قلم جاف» وهايلايتر أصفر.
2. إطار صفحة بزوايا crosshair وخطوط سطور كراسة وهامش أحمر خفيف.
3. خط حبر واحد متصل بيترسم مع السكرول من الـHero للـCTA.
4. ريفيل بالسطر للعناوين، وكلمة بكلمة للمانيفستو. **ممنوع تقسيم الحروف العربية.**
5. مشهد sticky للمراحل (دعوة ← فصل ← تسليم ← قرار) بواجهة حية بتتبدّل طبقاتها.
6. مؤشر أقسام جانبي وشريط تقدم، marquee واحد بس، وCTA بلوك بالأزرق.

## اللي هنتجنبه

- تسلسل صور أو canvas في الـHero (اترفض صراحة).
- Lenis أو أي scroll hijack: الاتنين بيستخدموه، بس إحنا محتاجين سكرول المتصفح الطبيعي عشان الكيبورد والـRTL والأداء.
- مكتبات تقيلة (GSAP/Three) من غير احتياج مقاس.
- أرقام أو إحصائيات مخترعة.
